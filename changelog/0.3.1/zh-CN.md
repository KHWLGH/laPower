# 0.3.1 - 2026-11-26

## 新增

- 新增“使用系统时间显示”开关（设置 → 图表与记录），开启后监控图表 X 轴、时间线、悬停提示、打点及 PD 报文时间列按系统时钟显示（仅影响界面显示，导出的 CSV 与 PD 文件始终同时记录系统时间与软件/时间戳两种时间）。
- PD 捕获 JSON 导出条目新增本地 `systemTime`（`YYYY-MM-DD HH:MM:SS.mmm`）字段，同时保持旧版文件兼容导入。
- 新增自定义字体设置（设置 → 外观与语言）：按界面语言适配对应项（简/繁中文为中文字体 + 英数字体，日文为日语字体 + 英数字体并补充日文原生默认字体栈，英文为界面字体 `Interface font` + 等宽数字字体 `Monospace & numeric font`），支持枚举本机已安装字体及字面、按字符范围独立生效不串扰、默认项显示当前系统默认字体名称，并提供磨砂玻璃风格实时预览与恢复默认字体。

## 变更

- 重构导出及临时恢复 CSV 的时间列为 `SystemTime`（`YYYY-MM-DD HH:MM:SS.mmm`）与 `SoftwareTime(s)`（精确秒数），去除重复时间列与 `="..."` 包裹，并完整兼容历史旧版 CSV 导入。
- 优化监控图表 X 轴时间刻度密度与边缘防裁边逻辑：按绘图区宽度保持恒定等分密度并始终完整显示起止时间（极窄时优先保留结束时间），消除拖动、平移和缩放时的密度跳变、边缘空档与标签重叠/裁剪。

## 修复

- 修复记录过程中将底部时间线拉杆（右柄或选区条）拖到最右侧松手时未进入跟随模式、仍停留在拖拽前固定区间的问题。

## 性能与维护

- `SeriesBuckets` 重构为按 X 轴像素列精确投影的 M4（首、最小、最大、末）聚合，解决长程记录与非均匀采样下按样本序号等分导致的锯齿、尖峰漂移与时间错位。
- `ExactExtremaIndex` 为粗层级引入紧凑 Float32 极值包络缓存并按可见通道掩码跳过隐藏通道，将百万点缩放/平移极值重算降至约 3 ms。
- 收紧实时与交互像素预算（动态密度 1–4 物理像素、移除手势 160 桶粗降采样上限、像素中心采样对齐及稀疏覆盖表清理），兼顾百万点流畅度与波形细节保真。
