# 0.3.0 - 2026-11-24

## Added

- Integrated and refined frosted-glass surface styling and UI transitions from upstream PR #11 across workspace views, dialogs, flyouts, and protocol views, adding Settings → Appearance & language controls for `Custom background`, `Background image opacity` (0–100%, default 100%), and `Background image blur` (0–40 px, default 14 px). Local PNG, JPG, or WebP images up to 25 MB are saved locally and restored on startup, and `Clear` resets to the default backdrop; no built-in default wallpaper is bundled. Preserves Windows-style right-side window controls on Windows/Linux and native window controls on macOS, `--font-ui` / `--font-mono` typography, and Follow system / Light / Dark themes.
- Refined top toolbar spacing and dividers, and centered the bottom status bar with a play/pause recording toggle icon on the left (showing play while paused and pause while recording) alongside duration, sample rate, point count, and remaining capacity.
- Enhanced chart navigation and per-channel styling: wheel zoom works on both the main chart and overview timeline navigator, zoomed views support drag-to-pan and smooth live-follow restoration, and `Adjust line thickness on zoom` (enabled by default) plus per-channel color, line width, and vertical offset controls (`0` resets) are persisted. Preserves clean quantized integer/round Y-axis ticks, signed/unsigned current recording semantics, and full column-store sample accuracy.
- Added the Windows x64 portable ZIP release target (`*_windows-x64_portable.zip`) alongside MSI and NSIS installers, bringing releases to eight verified packages with `SHA256SUMS`.
- Switched KM003C polled ADC sampling (`src-tauri/src/km003c_session/`) to instantaneous voltage/current fields (`vbus_instant_v()` and `ibus_instant_a()`, computing `power = voltage * current`) so firmware display averaging does not hide subsecond changes.
- Refined the PD splitter handle and interactions, redesigned the protocol detection image report layout, and fixed the main chart top legend so it stays horizontally centered instead of shifting left next to the Mark button group.
- Added single-line contributor credits summarizing each contributor's changes for [weixunkkkkk](https://github.com/weixunkkkkk) (#1), [asdmoment](https://github.com/asdmoment) (#4–#9), and [xiaokangzaina](https://github.com/xiaokangzaina) (#11) across all four localized README files.

## Performance and maintenance

- Optimized the WebView2 Canvas 2D / `OffscreenCanvas` incremental pixel-bucket rendering pipeline with 2D horizontal dirty-rectangle redraws (replacing full-canvas clears), cached channel column lookups, off-screen column skipping, zero-allocation hover/pan/zoom loops, packed RGBA writes, and a 3-point affine fast path for aligned series.
- Hardened streaming, security boundaries, and modularity: removed frontend `fs:*` capability permissions and the unused direct `tauri-plugin-fs` dependency, routed PD import and trigger-history text export through controlled backend file handles, aligned report energy/time-weighted averages with monotonic relative time to avoid host clock jumps, and split large frontend and backend modules.
- Added `bench/chart-zoom.mjs` microbenchmark, and reorganized and streamlined the localized READMEs, [user guide](../../docs/en/USAGE.md), [development guide](../../docs/en/DEVELOPMENT.md), [architecture guide](../../docs/en/ARCHITECTURE.md), and [performance guide](../../docs/en/PERFORMANCE.md).
