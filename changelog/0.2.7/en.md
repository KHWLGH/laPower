# 0.2.7 - 2026-11-20

## Added

- Added a Windows x64 portable ZIP release that can be extracted and launched without installation.
- Added wallpaper, liquid-glass styling, and motion effects inspired by the Mia Developer Toolkit while preserving the existing page layout.

## Changed

- Unified the backgrounds of the monitoring, PD analysis, and protocol-control pages; removed monitoring readout separators while retaining the four colored readout bars.
- Set Microsoft YaHei as the preferred UI and chart font, and refined the translucent frosted-glass surfaces, highlights, and control outlines.
- Removed the window-style switcher and fixed Windows and Linux to the Windows style; increased the transparency of glass cards.
