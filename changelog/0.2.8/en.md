# 0.2.8 - 2026-11-20

## Changes

- Add a custom PNG, JPG or WebP background between theme and language settings. The image is saved in the user configuration directory and restored on startup.
- Remove settings and monitoring toolbar dividers and the live-statistics panel backing; move recording status, duration, sample rate, point count and remaining capacity into the center of the monitoring toolbar.
- Smooth chart transitions and add animated transitions when switching workspaces and protocol subviews, respecting the system reduced-motion preference.
- Move connection status next to the title-bar Connect control and remove the bottom status bar.
- Add custom colors for voltage, current, power and temperature curves, keeping chart, legend and live readings synchronized.
- Merge the main chart and range preview into a single glass surface without internal card borders or gaps.
