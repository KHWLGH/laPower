# 0.2.6 - 2026-11-14

## Added

- **Image and video reports:** Export an entire recording as a lossless PNG or a 1–60 second time-lapse video from Monitor. Options include 720p–4K, light/dark themes and curve selection, with saved preferences. PNG reports offer a 16:9 layout with up to eight markers or a long image retaining all markers; markers and marker details can be selected independently. Reports include statistics, capacity and energy. Videos support MP4/MOV, H.264/H.265, 24/30/60 fps, automatic/hardware/software encoding and three quality levels. Linux uses built-in H.264; macOS supports VideoToolbox and a built-in H.264 fallback. No ffmpeg installation is needed; H.265 availability depends on system encoders.
- **POWER-Z protocol detection:** A dedicated Detection tab for KM003C/KM002C shows per-protocol status, returned voltages, evidence and live stages. Supported, unsupported, unchecked and unconfirmed results are distinct, as are VOOC/SVOOC and MTK PE 1.0/2.0. Full detection tries the extended scan first, falls back to the regular scan if it does not finish, then probes missing results. Supported protocols can fill the trigger form for explicit confirmation.
- **Protocol detection image reports:** Export this detection's protocol states, voltages, PD version and complete PDO parameters to a 16:9 PNG at 1080p, 1440p or 4K. Light/dark theme and resolution preferences are independent of Monitor reports. AVS bands and reported power are preserved, with calculated reference values identified. Partial, cancelled and timed-out detections and unconfirmed resets remain explicit. Opening the dialog freezes the detection snapshot.
- **Offline license reader:** Settings → About now opens a reader for the full project GPL/LGPL texts and runtime component notices, with document switching and context-menu copying of selected text. Central copyright scope, original JohnScotttt attribution, the complete LGPLv3 text, publisher and license metadata are included, preserving third-party rights and provenance records.
- **Development commands:** Tiered local cleanup can remove frontend output, incremental caches, build output or dependencies, with a dry run and protections for source, tracked files and user data. A shared headless interface exposes isolated simulated sessions, virtual time, consumption ACK waits and diagnostics to other scripts.

## Fixed

- **Protocol detection and PD versions:** PD is checked through a separate session and PDO read after other protocols, rather than reusing list-scan PD status. Version display prefers a validated, complete Get_Revision response while retaining the meter report and the minimum version established by PDOs. A lower response cannot override the PD 3.2 minimum established by SPR AVS; conflicting evidence is shown explicitly. Structured fields, revision/version pairs and complete hexadecimal frames are accepted, while Sink echoes and incomplete frames are rejected. Raw exchanges remain available. Query failures preserve confirmed PDOs and support status without changing PDM settings.
- **Detection, triggering and reset results:** Empty replies and partial scans no longer appear successful; a new scan clears old results. A scan that finishes normally with unconfirmed items is no longer treated as a command failure. Cancellation preserves this run's results and waits for backend completion before unlocking controls. Probes and resets verify fresh voltage samples; cancellation immediately attempts a reset and 5 V verification. Trigger requests require their own reply confirmation, even when protocol entry succeeds.
- **Protocol parameters and capabilities:** Fixed UFCS capabilities being labeled as PD PPS, lost capability positions and incorrect request routing. Fixed PDOs show their actual voltage and omit invalid voltage arguments. PDM settings are reapplied and confirmed on opening, reopening and CDC recovery; custom commands invalidate stale confirmations, and hexadecimal input rejects invalid characters. Corrected MTK PE version/boolean parsing, repeated PDO reads and plain-text EPR positions.
- **Command history and evidence:** Preserved trailing lines across serial chunks, cancellation and read errors. Completed commands retain expanded progress, including late steps, recovery and retry commands. Repeated acknowledgements, voltage changes and connection states remain in their original order. Long replies no longer hide progress; truncation is explicit and expansion/scroll state is preserved. Each protocol shows only its own evidence.
- **Report export reliability:** CSV imports enable reports as soon as two data points are available. Fixed invalid-data errors on dense four-channel recordings, dropdown layering and keyboard interaction. Out-of-range video lengths show an error and disable generation. Preparation freezes samples, markers and provenance, yields between chunks and supports cancellation. Jobs continue after closing the dialog, reopen with their actual options, and retain progress across temporary status-query failures. Failed or cancelled exports preserve existing files and clean up temporary output.
- **Video encoding:** Capabilities are probed and cached for the selected combination; the actual encoder is displayed when encoding starts and after completion. Windows skips software display adapters and tries available GPUs; when the GPU path fails, system-memory frames may still use a hardware encoder. Hardware encoding is reported only after successful validation, with explicit fallback reasons. Bitrate calculation, disk-space checks, parameter cards, headings, curves and marker layout were refined.
- **Curve shading and fonts:** View → Curve shading is now a saved manual switch, enabled by default. It retains per-channel opacity and no longer changes automatically during recording, pausing or zooming. Axis-width measurement now restores the Canvas font, keeping initial rendering and resizing consistent.
- **Capture, recovery and export boundaries:** PD gap recovery follows the contiguous consumption cursor in bounded pages and validates the generation, isolating clears, imports and late replies. On-demand details use an eight-entry cache. Recovery files no longer rewrite and sync the same persisted version repeatedly. External TCP temperature input uses bounded chunks and line buffers, preventing unbounded memory growth and delayed shutdown on input without newlines.
- **Windows development builds:** Restored zero optimization for libc in development builds to address Kaspersky blocking its build script on the verified local Windows/MSVC setup.

## Performance and maintenance

- Navigation reuses the power extrema index and display buffers, avoiding a full-history scan on resize. Range statistics reuse a Worker and bounded transfer buffers while isolating late results from cancelled tasks. Raw samples, endpoints, extrema, gaps, cursor precision and integration semantics are preserved.
- Continuous diagnostic animation is disabled by default, and global updates are combined outside Monitor. PD and protocol display work stops while hidden or minimized and synchronizes immediately on return. Empty backend emission queues block instead of waking periodically.
- Core tests are restricted to the project test directory, avoiding local output copies. Screenshots, UI checks and existing browser benchmarks share the headless interface. Duplicate acceptance scripts were removed, deterministic build checks were folded into core CI, and timing benchmarks remain available for local use.
