# 0.2.4 - 2026-10-13

## 变更

- 低于仪表原始采样率的档位改为窗口平均：电压、电流、功率和 D+ / D− 使用窗口内全部帧的平均值，时间戳、CC 与温度取最后一帧，不再只保留电流绝对值最大的帧。默认 4 次/秒也适用；WITRN 100 次/秒和 POWER-Z 1000 次/秒不受影响，短于采样间隔的尖峰会被平均。在已有的 70 分钟 WITRN K2 无线充电记录回放验证中，100 ms / 250 ms / 1 s / 10 s 档的累计能量偏差由峰值保持时的 +0.90% / +1.18% / +1.71% / +2.84% 降至 ±0.11% 以内。
- 完整常量数据块共享存储，降低空通道、稳定信号线、记录段号和采样间隔的内存占用；CSV 导入收尾逐块补齐，保留精确值与全部历史数据。
- 窗口风格移除「跟随平台」：Windows / Linux 默认使用 Windows 风格并迁移旧自动配置，macOS 继续使用原生红绿灯。
- 更新日志按版本归档：旧版本中文说明迁入 `changelog/<version>/`，根目录仅保留版本索引；新版本提供英文与简体中文 Markdown，开发期间只维护中文草稿。新增发布准备与预览命令，Release 默认展开英文、折叠简体中文，保留安装包校验和草稿重试保护。
- 精简文档体系：README、使用指南、开发与构建维护四语言，外部温度服务并入开发指南；架构、性能与协议库说明维护中英双语，移除重复入口和一次性历史报告。
- 更新 0.2.4 简体中文、繁体中文、英文与日文的浅深主题预览图，覆盖监控、PD 分析、协议控制与设置四个页面；保留完整软件标题栏，并使用一致的 120 秒模拟数据。

## 修复

- WITRN 100 次/秒采集时，读线程迟醒后一次读出的积压报告不再因共用读取时间戳而落入同一采样窗口、被合并丢弃；先排空队列，再按设备节拍（≤ 10 ms）回推时间戳。在已有的 macOS 70 分钟、425,121 点实测记录中，旧逻辑在 84 次迟醒期间合并掉约 149 帧（0.035%），单次最多 19 帧。
- 录制开始、暂停、继续及采样率切换前先排空 WITRN 旧报告，并为下一批回推时间戳设置屏障下限，避免积压样本被归入新录制段或压成相对时间 0；超过排空上限时明确停止，保留已记录数据。
- 修复粗采样下正反向电流相抵导致 Wh / mAh 少计：电流方向显示使用有符号均值，功率、能量和容量使用逐帧幅值均值；范围统计、CSV 和临时恢复文件保留同一积分口径，按需追加 `CurrentMagnitude(A)` 列，兼容旧文件。
- 「跟随系统」括号内显示检测到的系统语言，手动切换界面语言不会改变它；未支持的系统语种保留真实名称，界面回退英文。
- Windows 简体中文与繁体中文统一优先使用微软雅黑 UI，改善正黑体在小字号下笔画偏细、发虚的问题；正黑体保留为缺字回退，表单与图表字体同步切换。
