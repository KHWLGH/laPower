# Unreleased

## 修复与优化

- GitHub 跳转按钮使用 GitHub 标志，应用版本统一更新为 0.2.5。
- 关于页改为自适应横向应用信息卡片，增加 GitHub 快捷跳转和仅手动触发的更新检查；新版通过浏览器前往对应发布页下载，不增加常驻提示。
- 第三方组件展示用途、版本与许可证，可离线展开查看覆盖四个桌面发布目标的全部运行依赖；新增清单生成与 CI 一致性检查。
- 滚动条保持固定宽度并预留空间，避免悬停或内容变化引起跳动；设置目录支持平滑定位、中断和减少动态效果偏好。

- 自动暂停和温度服务统一为与导出 CSV 一致的分体下拉按钮；设备信息移至标题栏刷新与连接之间的纯信息图标，未连接时也可查看选中设备。
- 设置保留单页滚动，增加自适应固定目录与滚动高亮；恢复与重置独立分组，关于移至页尾，切换工作区后保留滚动位置。
- 图表填充改为每通道一次合成，复用坐标与区间缓存；暂停接管最新完整窗口，热索引直接准备精细图，冷暂停在首张完整图绘制后细化，减少重复绑定与导航图抢帧。
- KM003C 序号空洞与已验证重放改为连接期间累计诊断，限频记录并在断开时汇总。

- 修复图表中等缩放时陡峭曲线断成分立短条或杂点的问题，并扩大有界原始点显示范围，改善缩放细节。
- 图表降采样按真实采样顺序保留首末点与极值时刻，缺测处断线，完全放大后也使用折线；主图和功率导航图共用有序几何。
- 极值索引按下标和有限值计数分页保存，减少内存与追加开销；冷暂停先显示已有完整粗图，后台完成后一次升级细节，缩放、换源与隐藏会取消过期任务。

## 新增

- 打点新增“立即打点”模式，可在“设置 → 图表与记录”切换：开启后点击按钮或按快捷键直接使用默认标签打点，再从标记列表改名；默认保留先输入标签的流程，选择自动保存。
- 新增打点标注：记录时点击 `打点` 或按 `M` 给当前时刻写标签（例如电量 50%），标记落在点击之后到达的下一个点上；鼠标停在主图上时按 `M` 标记光标下的点，便于回看时补标。主图显示竖线和标签（挨得近的最多错开三行），时间线导航器显示刻度；标记列表可改名、删除。导出的 CSV 增加可选的 `Marker` 列，没有标记时不写这一列，旧文件照常导入；临时恢复文件固定带这一列。标签去掉分隔符、引号与换行，开头的 `=`、`+`、`-`、`@` 换成全角字符，避免被电子表格当成公式。
- 应用内对话框支持单行输入（`promptText`），回车确认、输入法组合中的回车不算确认。
- CSV 表头在 `DateTime` 之后增加来源行：`Software`（写文件的软件与版本）、`Device`（采集这份数据的仪表型号与 USB VID:PID）、`Points`（每个点如何从仪表帧得到，`mean` 为采样间隔内全部帧的平均值；来源混合或未知时不写）。导入时读取并在再次导出时保留，临时恢复文件同样写入；旧文件和旧版本照常互相导入。
