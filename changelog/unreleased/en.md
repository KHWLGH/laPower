# Unreleased

## Improvements

- Use the GitHub mark for GitHub navigation buttons and update the application version to 0.2.5.
- About now uses a responsive horizontal application card with a GitHub shortcut and manual update checks. New releases open in the browser for download, without persistent update prompts.
- Third-party components show their purposes, versions and licenses, with an offline expandable list covering runtime dependencies across all four desktop release targets and a CI consistency check.
- Scrollbars retain their width and reserve space to prevent layout shifts. Settings navigation scrolls smoothly, supports interruption and respects reduced motion preferences.

- Auto pause and temperature service now use split dropdown buttons matching CSV export. Device information is available through an icon between refresh and connect, including the selected device before connection.
- Settings now has a responsive sticky directory with scroll tracking. Recovery and reset have their own section, About appears at the end, and switching workspaces preserves the scroll position.
