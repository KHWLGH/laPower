# 0.2.2 - 2026-10-04

## Added

- GitHub Actions 支持 Windows x64、Linux x64、macOS Intel / Apple Silicon 四目标打包；手动触发提供安装包附件，版本 Tag 在全部检查、打包与远端 SHA-256 验证通过后自动公开 Release。macOS 使用 ad-hoc 签名并保留 12.0 最低部署目标。
- Release 自动从对应版本的更新日志生成中文发布说明，包含新增、变更、修复、移除和三平台安装说明；更新日志缺失或为空时停止发布。
- 新增统一版本更新命令 `npm run version:set -- X.Y.Z`，同步 npm、Cargo、Tauri 配置与两个锁文件的工作区版本，开发版本更新为 0.2.2。
- 支持 POWER-Z KM003C / KM002C 的 Vendor Bulk 采集、ADC 温度和 PD 报文，新增独立的 LGPL 协议库 `crates/km003c`。
- POWER-Z 支持认证后的 AdcQueue 1000 次/秒采样；认证失败时回退到 100 次/秒并提示原因。设备列表和采样率选项按设备能力显示。
- 新增 POWER-Z 协议控制工作区：PDM、PDO 读取、电压触发、协议检测、QC3 步进、高级命令与取消操作。断开或 Bulk 重连自动结束 PDM 会话。
- 新增临时恢复文件和单次记录上限：默认开启缓存恢复，记录上限默认 512 MB，可设为 64–8192 MB。启动后可恢复或删除未正常结束的记录，长期保存需显式导出。
- 新增独立开发展示工具 `tools/showcase/`，提供虚拟设备、模拟数据与界面截图；默认浅色，不进入安装包。
- 关于页在版本号上方展示软件图标，与桌面图标共用资源。
- 新增算法、Rust 热路径、PD 元数据、启动分段与发货形状基准。启动支持同批交替 A/B；计时结果仅用于报告，CI 硬性检查发货形状与基线结构。性能说明见 [性能基准与边界](../../docs/PERFORMANCE.md)。

## Changed

- 项目更名为 **laPower**，应用标识改为 `io.github.khwlgh.lapower`，可执行文件改为 `lapower`。使用独立设置与缓存目录，不自动迁移 WITRN-RS 设置；旧 CSV / PD 捕获文件仍可导入。
- 主题顺序调整为 **跟随系统 / 浅色 / 深色**，首次运行与重置配置默认跟随系统；保留已有主题选择。文档预览以浅色优先。
- 更新软件图标，保留大圆角与近白色背景，生成适合不同图标尺寸的 PNG、ICO、ICNS 及平台资源。
- 前端由构建生成的 `out/` 发货，9 个阻塞样式表合并为 1 个。开发构建保留原生 JS 模块，发布构建分别合并应用入口与 Worker；Cargo 构建前必须生成最新前端产物。
- 图表使用分块列存储、可见窗口 min/max 桶和协作切片，完整保留原始样本。显示密度依据实际绘制反馈自适应调整，拖动与松手使用一致的窗口投影。
- 1000 次/秒采样的自动绘图默认约 20 帧/秒，绘制压力较高时可降至约 10 帧/秒；拖动、滚轮、键盘和松手刷新绕过限帧。100 次/秒的健康绘图不因历史变长固定降刷新率，采集、保存、统计及积分保持完整精度。
- 录制与回看分别维护显示预算；同一次连续交互保留有效的绘制压力反馈，放大到稀疏窗口时恢复原始点。图表性能的测量口径及仍需实机覆盖的场景见 [性能基准与边界](../../docs/PERFORMANCE.md#测量与硬件边界)。
- 面积填充与显示分桶独立控制：健康的密集刷新保留用户填充，持续慢帧先降密度，再按实际绘制压力关闭填充；稳定后有界尝试恢复。
- 大范围精确统计与 CSV / PD 导出采用分块 Worker；统计按计算耗时调整刷新频率并标明已完成范围。CSV / PD 文件通过受控的 Rust 文件句柄分块读写，单块最多 4 MiB。
- CSV 数值保留可往返精度，并保存精确相对时间、绝对时间戳、可选录制段和逐点采样间隔。积分空档阈值按 `max(2 秒, 8 × 采样间隔)` 计算，支持混合采样率。
- 工作区 Rust 最低版本提高至 1.85；开发依赖使用优化构建，桌面库仅生成 `rlib`，打包格式显式列出。
- 同步使用、架构与构建文档，修正失效链接、过期测试数量、信号线分辨率、文件格式及恢复设置说明；历史 macOS 构建记录保留当时的产品名与产物路径。

## Fixed

- 修复 macOS 自动打包后的校验失败：同时构建 APP 与 DMG，保留应用供架构、签名和最低系统版本检查，发布附件仍只提供 DMG。
- 修复 Windows 小图标的暗色边缘：背景直接过渡到透明，重新生成各尺寸边缘覆盖率；窗口按 DPI 从 EXE 资源加载原生图标，资源随图标变更重新编译。
- 修复 POWER-Z 高速队列的已接收样本重放导致时间倒退；仅跳过逐字段核实的重复前缀，无法核实的倒序或冲突明确停止采集并保留已有记录。
- 修复采集节拍偏移导致漏选样本，以及固定 8 ms 发射窗口无法有效合批的问题；使用节拍网格选点与按采样间隔调整的合批窗口。
- 修复终态流错误后无法断开、重连或退出的问题；允许显式退休已停止的失败会话，保留真实的未消费状态。
- 修复恢复文件的小记录滞留、同步失败误删除与碰撞名称漏扫描；增加原生每秒检查点，大回填使用固定快照。
- 修复慢采样档能量恒为零、非有限样本污染范围均值，以及历史采样率与当前设置不一致导致积分错误的问题。
- 修复密集跟随时完整投影不能及时提交，以及 WebView2 最小化后仍报告页面可见的问题；按原生窗口状态取消准备，恢复后提交积累数据。
- 修复从右端缩小窗口或向较早位置平移时反复重建有效极值索引的问题；取消旧窗口投影仍保留已完成的索引前缀，新增样本只补建尾部。
- 修复已索引窗口按原始点数分片造成持续拖动期间曲线不更新的问题；按实际桶查询量准备数据，先执行约 4 ms，剩余工作协作分片，并合并最新窗口请求。
- 修复大数据回看在慢帧后长期停留于粗糙宽桶的问题：按画布实际像素分辨率保留细节，放大后恢复原始点；准备耗时不再误触发降密度。回看填充拆为独立条带，曲线采用有界像素列位图，关闭填充时合并上传；连续窗口保留已确认的填充保护，未知填充反馈未完成时合并最新交互输入，避免反复排队。
- 修复导入密集数据后导航缩略图曲线缺失的问题：主图像素列优化只作用于主图，导航图保留独立的 uPlot 描边和分桶路径；主图缩放不改变导航全历史投影，导航重绘不清除主图填充缓存。
- 设置写盘失败向用户提示；本机温度源随仪表断开复位，清除冻结读数并解除来源控件锁定。
- 修复标题栏控件的事件目标处理、macOS 风格按钮溢出与贴边、macOS 风格下的 Windows 贴靠浮窗，以及分栏手柄丢失指针捕获后无法恢复的问题。
- 修复下拉箭头的 `data:` 资源被 CSP 拦截、构建产物陈旧仍被嵌入，以及声明文件与工具临时文件误入安装包的问题。

## Removed

- 移除 Mica 与非聚焦窗口材质设置、相关依赖和命令。窗口改为不透明，旧材质设置在读取时丢弃。
- 移除未使用的 Codicons 字体与死资产。
- 移除浏览器长跑 harness、硬件验收脚本、发布前置回执流程及对应表面回归。CI 保留核心测试、类型检查、lint、Rust 检查、协议 feature 组合和确定性性能检查；真机验收按需手动执行。
