# 0.2.5 - 2026-10-17

## 新增

- 新增打点标注：点击「打点」或按 `M` 为记录添加标签，也可在主图上为光标下的数据补标。主图显示竖线与标签，时间线导航器显示刻度；标记列表支持改名和删除。「设置 → 图表与记录」可开启「立即打点」，直接使用默认标签，之后再改名。标签会清理分隔符、换行和公式前缀，便于在电子表格中使用。
- 快捷键可在设置中重新绑定、解除绑定或恢复默认，按钮提示同步更新。默认 `P` 启停记录、`M` 打点、`Ctrl+O` 导入、`Ctrl+S` 导出、`Ctrl+Shift+S` 联合导出；macOS 使用 Command 代替 Ctrl。输入文字、使用输入法、打开对话框或录入快捷键时不会触发业务操作。
- CSV 导出可分别选择是否包含温度、设备信息和打点，并保存偏好；主按钮直接按已保存选项导出。新增「同时导出 CSV 和 PD 数据」，一次选择位置，在同一目录生成 `.csv` 和 `.pd.json`，分别报告写入结果。两份文件使用同一时刻固定的数据快照；PD 未跟随记录时提示时间范围可能不同，不自动裁剪或对齐。
- CSV 新增 `Software`、`Device` 和 `Points` 来源行，记录写文件的软件版本、采集仪表及采样规则；导入后再次导出时保留来源，未知或混合的采样规则不作推断。可选 `Marker` 列保存打点，临时恢复文件也保留标记和来源信息，旧文件仍可导入。
- 关于页增加 GitHub 快捷入口与手动更新检查。仅点击「检查更新」才请求 GitHub 正式发布信息，发现新版后可前往对应发布页下载；结果留在关于卡片内，不自动检查、下载或安装，也不增加常驻提示。第三方组件展示版本、用途和许可证，并可离线展开查看四个桌面发布目标的直接及间接运行依赖。

## 调整与优化

- 更新四语言、浅深主题的文档截图至 0.2.5，并将整套截图生成、逐张检查及 README 同步纳入每次发布前的必做步骤。
- 自动暂停和温度服务采用与导出 CSV 一致的分体按钮，主按钮负责启停，箭头打开配置。设备信息移至刷新与连接之间的纯信息图标，优先显示已连接设备，否则显示当前选中设备；未连接时也可查看。
- 设置保留单页滚动，增加宽屏左侧、窄屏顶部的固定目录与滚动高亮；目录按完整标签留宽，避免英文换行。恢复文件、恢复列表和重置设置归入「恢复与重置」，关于放在页尾并改为自适应横向卡片。切换工作区后返回设置可恢复本次会话的滚动位置。
- 滚动条保持固定宽度并预留空间，避免悬停或内容变化造成布局跳动。监控左侧读数栏隐藏滚动条及其占位，矮窗口仍可滚动查看全部读数。设置目录支持平滑定位，用户滚动可中断，并遵循「减少动态效果」偏好。
- 温度采集、曲线显示和 CSV 温度列分别控制。断线保留温度来源、显示与导出偏好及已有数据，缺测区间留空；导入或清空数据不改变连接偏好，导入温度列不触发连接，重启后仍需手动连接。
- 图表降采样按真实采样顺序保留首末点与极值时刻，主图和功率导航图共用有序几何；极值索引按页保存，减少内存与追加开销。每通道复用坐标、区间与填充缓存，减少重复合成和暂停、缩放时的重复绘制。

## 修复

- 修复中等缩放时陡峭曲线断成分立短条或杂点的问题，扩大有界原始点显示范围；缺测处断线，完全放大后仍使用折线。
- 暂停时接管最新完整窗口；热索引直接准备精细图，冷暂停先显示完整粗图，再在后台完成后一次升级细节。缩放、换源或隐藏图表会取消过期任务，减少导航图与主图抢帧。
- KM003C 序号空洞与已验证重放改为连接期间累计诊断，限频记录并在断开时汇总，便于排查采集端异常；此项不代表仪表端序号空洞已被消除。
