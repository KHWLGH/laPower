## 開始使用

1. 將儀表的資料介面連接至電腦。在標題列點擊重新整理圖示，從裝置下拉清單選擇儀表，再點擊 `連線`。Linux 使用者請先設定 [udev 規則](DEVELOPMENT.md#udev-規則必需)。
2. 開啟 `監控`，選擇 `取樣率`；首次預設是 `4 次/秒`。連線後的大字讀數會即時更新，但尚未開始記錄。
3. 點擊 `開始記錄`。圖表開始累積資料，底部點數增加，記錄的統計值和累計量隨之更新。切換工作區不會暫停記錄。
4. 如需溫度，依 [溫度服務](#溫度服務) 的步驟單獨啟用；只連接儀表不會自動啟用溫度。
5. 點擊 `暫停記錄` 查看資料，或點擊 `繼續記錄` 接續同一份記錄。暫停期間即時讀數仍可變化，圖表和累計量不再增加。
6. 點擊 `匯出 CSV` 選擇儲存位置。需要溫度或調整匯出內容時，先開啟右側箭頭。長期保存請明確匯出，暫存復原檔案不能取代匯出檔案。

## 介面總覽

### 標題列

左側常駐 `監控`、`PD 分析`、`協定控制` 三個工作區入口。右側依序是裝置選擇、重新整理圖示、資訊圖示、連線／中斷按鈕和設定齒輪。Windows 與 Linux 使用右側的 Windows 風格視窗按鈕，macOS 使用左側的系統原生按鈕。

| 入口 | 用途 |
| --- | --- |
| `監控` | 即時讀數、圖表記錄、打點及 CSV 匯入匯出 |
| `PD 分析` | USB-PD 擷取、報文檢視及 PD JSON 匯入匯出 |
| `協定控制` | POWER-Z 的 PDM、協定偵測和電壓觸發；入口一直顯示，連接支援的 KM003C/KM002C 後才啟用控制操作 |
| 設定齒輪 | 外觀與語言、圖表與記錄、快速鍵、復原與重設、關於 |

窄視窗下部分入口只顯示圖示，懸停可查看名稱；文字顯示不全時，可在設定中調低 `介面縮放`。

### 裝置連線與裝置資訊

資訊按鈕只顯示資訊圖示，位於重新整理與連線之間。點擊可查看型號、`VID`、`PID`、`SN` 及說明：優先顯示已連接儀表，否則顯示目前選擇的儀表；沒有裝置時顯示空狀態。未連接也能查看，選擇裝置或更新清單後會同步更新。

裝置名稱可能含 USB 連接埠，例如 `WITRN K2 (USB 4-4)`；同一實體裝置篩選後仍有多個 HID 介面時，還會追加介面資訊。WITRN 序號可能重複，請配合連接埠區分同型號儀表。連線期間不能改選儀表，請先點擊 `中斷連線`。

### 狀態列

底部顯示記錄狀態、時長、取樣率、已記錄點數、剩餘記錄容量／預計時間及連線狀態。點擊左側記錄狀態也能開始或暫停主監控記錄；開始需要已連接的儀表。時長和點數反映記錄資料，不是儀表連線時間。

| --- | --- |

| `取樣率` | 設定即時取樣間隔，見下表 |
| `匯出 CSV` 主按鈕 | 依已儲存選項匯出全部記錄；圖表選取範圍不限制匯出範圍 |

| `一鍵重設` | 記錄中停用；暫停後點擊並確認，清空圖表、統計、累計量和標記。PD 開啟跟隨記錄時也清空 PD 報文 |

主操作與箭頭獨立。開啟設定不會開始記錄、啟用自動暫停或連接溫度來源。點擊浮出面板外可關閉；Escape 關閉後焦點返回開啟面板的按鈕。

### 取樣率

| 選項 | 間隔 |
| --- | --- |
| `1000 次/秒` | 1 ms；僅 POWER-Z KM003C/KM002C 可用 |
| `100 次/秒` | 10 ms |
| `10 次/秒` | 100 ms |
| `4 次/秒`（預設） | 250 ms |
| `2 次/秒` | 500 ms |
| `1 次/秒` | 1000 ms |
| `0.2 次/秒（5 秒 1 次）` | 5000 ms |
| `0.1 次/秒（10 秒 1 次）` | 10000 ms |

POWER-Z 不支援高速取樣或驗證失敗時，會退回 `100 次/秒` 並說明原因。慢速取樣將多個訊框彙整為一個點，短暫尖峰可能被平均；觀察瞬態時請選擇裝置支援的較高速率。匯入使用檔案的時間與間隔，不改變下次即時記錄的取樣率偏好。

### 讀數卡片

左側顯示電壓、電流、功率、溫度、累計能量、累計容量及訊號線。連線後大字數值是即時預覽；主卡下方的 `最小` / `平均` / `最大`（溫度為 `最低` / `平均` / `最高`）來自記錄資料。暫停後即時預覽的變化不是新的記錄點。

能量（Wh）及容量（mAh）由軟體對記錄積分計算；不計入暫停時間，繼續記錄保留累計值，匯入時依檔案重新計算。過長的資料空檔也會排除。啟用 `記錄電流方向` 後會顯示電流方向箭頭，功率與累計量依幅值計算。

拖動讀數欄右側分欄線可調整寬度，窄視窗會限制實際寬度。讀數放不下時，可在欄內使用滾輪或觸控板上下捲動；此區域隱藏捲軸且不保留空白。

### 顯示、圖表與時間線

- 開啟 `顯示` 選擇曲線。電壓、電流、功率和溫度預設勾選，D+/D-、CC1/CC2 預設關閉；勾選溫度不會連接溫度來源。
- 「顯示」頂部的「曲線陰影」總開關預設開啟，並儲存選擇。關閉時保留四條主曲線各自的不透明度，再開啟按原值恢復；錄製、暫停、拖曳和縮放都不會自動改變陰影。此開關只影響監控圖表。
- 四條主曲線各有 0–100% 填色不透明度，預設 15%；0 只關閉填色，不隱藏曲線。圖例表示目前可見通道，不能點擊切換。
- 懸停主圖查看該時刻可見且有效的通道值；在主圖使用滾輪，以游標位置為中心縮放時間範圍。
- 底部時間線兩端控制點調整範圍，拖動中間選區可平移。記錄時選區右端貼著最新資料會繼續跟隨；移到歷史區間則停留於該處。
- `僅統計選取範圍` 預設關閉。開啟後，最小／平均／最大與能量、容量只統計選區；大字即時讀數仍是目前預覽。不會刪除資料或限制匯出範圍，缺失值不參與統計。

繪製與資料擷取的頻率不同，細節見 [效能說明](../PERFORMANCE.md)（簡體中文）和 [架構說明](../ARCHITECTURE.md)（簡體中文）。

### 打點標註

1. 點擊主圖右上角 `打點` 或按預設的 `M`，輸入標籤後確認；預設標籤如 `標記 1`。
2. 記錄中按鈕標記隨後到達的下一個點，暫停時標記最後一點。游標位於主圖時按 `M`，則標記游標下最近的點；位置在開啟輸入框前確定。
3. 右側箭頭開啟標記清單；有標記時才可開啟。點擊標籤改名，留空或點擊刪除圖示可刪除。

在 `設定 → 圖表與記錄` 開啟 `立即打點` 後直接使用預設標籤，不再先詢問。標籤最多 40 字元，不適合 CSV 的分隔符會被清理。標記儲存在 CSV 的 `Marker` 欄，匯入會還原檔案中的標記；`一鍵重設` 會清空標記。

### 自動暫停

1. 點擊 `自動暫停` 右側箭頭，選擇 `電壓 <`、`電流 <` 或 `功率 <`。
2. 填入 `閾值` 與 `持續時間`（秒），關閉面板。
3. 點擊 `自動暫停` 主按鈕啟用，反白代表啟用；再開始或繼續記錄。

數值不高於閾值且持續指定時間時暫停。介面條件雖標示 `<`，目前判斷也包含等於閾值。持續時間為 0 時，首個符合條件的記錄點即可觸發。預設未啟用、條件為 `無`，閾值和時間均為 0；更改設定不會自動啟用，`無` 不會觸發。

### 溫度服務

溫度擷取、曲線顯示和 CSV 溫度欄是三項獨立操作。

1. 點擊 `溫度服務` 右側箭頭，選擇 `來源`。
2. 使用儀表溫度時選 `儀表` 並先連接儀表，不需外部程式。TCP 選 `外部`，輸入 `IP` 和 `連接埠`，預設 `127.0.0.1:1573`。首次來源預設外部且未連線。
3. 關閉面板，點擊 `溫度服務` 主按鈕連接。有效數值到達後顯示於溫度卡，並隨主監控記錄寫入資料。
4. 需顯示曲線時在 `顯示` 勾選溫度；要寫入 CSV，另行勾選 `包含溫度`。

連接期間不能修改來源、IP 和連接埠；請先透過主按鈕中斷。重新啟動後需手動連接。儀表溫度隨儀表中斷，外部 TCP 獨立；斷線保留歷史資料，缺失溫度留空。TCP 伺服器每行發送一個攝氏數字，範例見 [外部溫度服務](DEVELOPMENT.md#外部溫度服務)。

### CSV 選項與聯合匯出

CSV 箭頭中的三項設定會儲存：`包含溫度` 預設關閉，`包含裝置資訊` 和 `包含標記` 預設開啟。勾選但無資料時，溫度和標記欄仍保留空白欄位；來源未知時不會以目前連接的儀表補填。

同一面板的 `同時匯出 CSV 和 PD 資料…` 需要監控與 PD 兩側都有資料。選擇一次位置產生 `名稱.csv` 與 `名稱.pd.json`，覆寫前會確認。匯出全部資料，不受圖表選區或 PD 篩選影響；選好位置後固定快照，後續樣本不會追加到這次匯出。關閉跟隨記錄時，兩份資料的時間範圍可能不同，不會自動裁切或對齊。

監控命令列的 `匯出報告` 使用文件圖表圖示，可將整段凍結記錄匯出為 PNG 圖片或短影片。首次預設圖片，之後記住上次選擇；解析度（720p–4K）、主題及內容選項一併儲存。

`報告內容` 中，電壓、電流、功率、溫度、`打點` 與 `打點詳細資訊` 使用並列的核取方塊。後兩項獨立控制：僅勾選打點時只在曲線上顯示標記，詳細資訊則在下方顯示名稱、時間和讀數；也可僅顯示詳細資訊或全部關閉。圖片與影片皆支援。

PNG 使用無損靜態版式，包含完整曲線、總時長、點數、時間加權平均電壓與功率、峰值電流、最高溫度、累計容量及電量；缺測維持缺測文案，沒有播放游標或進度列，也不需要影片編碼器。

- `16:9` 為固定橫向畫幅，最多包含依時間排序的前 8 個打點，超過時明確提示。
- `長圖` 保留全部打點，開啟詳細資訊時增加高度。超過安全尺寸會報錯，可降低解析度或關閉詳細資訊重試，不會默默捨棄打點。

影片保留 MP4/MOV、H.264/H.265、24/30/60 fps、1–60 秒、畫質與編碼模式。整段記錄快放，最後一格對應最後記錄點，最多包含前 8 個打點。時長越界時禁止產生影片，隱藏的影片設定不影響圖片匯出。

點擊 `產生圖片` 或 `產生影片` 時凍結資料，選擇原生儲存位置後背景產生。圖片與影片共用單一任務；關閉對話方塊後繼續，重開恢復進度及實際選項。可按 `取消匯出`；完成、取消與失敗均有提示。成功才提交目標檔案，失敗與取消保留已有檔案並清理暫存檔。

### 影片畫質與編碼模式

匯出對話框新增 `編碼模式` 和 `畫質`，預設為 `自動`、`高清`，與其他影片選項一併儲存。切換模式或畫質會重新檢測目前組合，檢測完成前無法產生；對話框顯示目標位元率，實際檔案大小隨內容變化。

| 畫質 | H.264（1080p / 30 fps） | H.265（1080p / 30 fps） |
| --- | --- | --- |
| 標準 | 10 Mbps | 6.5 Mbps |
| 高清（預設） | 20 Mbps | 13 Mbps |
| 極清 | 30 Mbps | 19.5 Mbps |

位元率隨像素數和影格率線性縮放，H.264 最低 4 Mbps、H.265 最低 3 Mbps，上限為 240 Mbps。較高畫質通常需要更多空間與編碼時間。

`自動` 優先使用硬體，失敗後轉為軟體並顯示原因。`硬體編碼` 嚴格要求實際硬體編碼器：Windows 的 GPU 紋理路徑失敗時，可嘗試由 CPU 繪製後交給硬體編碼；兩條路徑都失敗時會提示。`軟體編碼` 直接使用軟體，不顯示硬體回退提示。macOS 依所選模式建立並核驗 VideoToolbox 工作階段，軟體 H.264 可由內建編碼器接手；軟體 HEVC 僅在系統實際支援時可用。Linux 僅支援自動或軟體模式的 H.264。不可用的組合會保留選項並說明原因，無需安裝 ffmpeg。

五張參數卡將名稱、統計摘要與主讀數分開排版。右上角分別標明電壓「範圍」、電流「最大」、功率「平均」、溫度「最大」和容量對應的「能量」；缺測時保留說明。摘要對應整段凍結記錄，主讀數隨影片時間變化。

### 先選擇記錄模式

`跟隨記錄` 預設開啟；同一個記錄按鈕在兩種模式的用途不同：

| 模式 | 按鈕與資料行為 | 清空行為 |
| --- | --- | --- |
| 開啟跟隨記錄 | `開始記錄` / `暫停記錄` 控制主監控與 PD；主監控暫停時不保留新報文。即使監控已有資料，PD 暫停後仍顯示 `開始記錄` | 任一側清空都清空監控與 PD，確認框會說明連動 |
| 關閉跟隨記錄 | `暫停記錄` / `繼續記錄` 只暫停／恢復清單更新；已連接儀表仍在背景緩衝報文，恢復後補入清單，不控制主監控 | 兩側分別清空 |

要暫停整個連動擷取，使用記錄按鈕；只想停留檢視清單並繼續緩衝，請先關閉跟隨記錄再暫停清單。切換工作區本身不暫停擷取。

### 清單與詳情

| 控制項 | 用途 |
| --- | --- |

## POWER-Z 協定控制

![協定控制範例](../screenshots/zh-TW/light-trigger.png)

[查看深色主題](../screenshots/zh-TW/dark-trigger.png)

此入口一直顯示。未連接或連接 WITRN 時顯示提示，控制按鈕停用；連接支援協定控制的 POWER-Z KM003C/KM002C 後才可操作。

工作區預設開啟 `觸發` 頁籤。頂部的 `PD 類型`、`線材模擬`、`Sink` 設定及即時 V/I/P 讀數由 `偵測` 與 `觸發` 共用；掃描結果和觸發請求分別放在對應頁籤。

### 讀取 PDO 並觸發

1. 在頂部選擇 PD 類型、線材模擬和 Sink，點擊 `開啟` 開啟 PDM。
2. 點擊 `讀取 PDO` 取得充電器檔位，或使用 `自動偵測` / `完整偵測` 偵測協定。
3. 點擊 PDO 列填入請求，檢查所選協定的序號、電壓（mV）、電流（mA）後點擊 `觸發`；選擇 PDO 列不會立即觸發。
4. 在回應記錄檢視結果。更改頂部 PDM 參數後按 `套用`；`復位` 退出目前協定並恢復預設 5 V，`關閉` 關閉 PDM。

命令執行期間其他命令停用，命令列會顯示 `取消` 和歷史活動狀態；等待後端確認結束後才能傳送下一條命令。命令歷史固定在工作區右側，記錄清單獨立捲動。歷史依命令分組，包含時間、參數、耗時、狀態、進度和回覆；可依命令、狀態及文字篩選，複製單筆命令或全部記錄、匯出文字，也可將歷史命令填入表單。複製和填入都不會重送命令。歷史僅保留於目前工作階段，最多保留最新的 64 KB。進階區提供 PD/UFCS 和自訂命令，自訂命令可在未開啟 PDM 時傳送，其餘協定操作需要 PDM。中斷或重新建立儀表擷取連線後，需重新開啟 PDM。此頁即時讀數與監控共用儀表連線。

執行進度會保留各步串口命令、回覆及恢復／重試過程，結束時補齊最終過程；取消或錯誤前已收到的內容也會保留。歷史的展開狀態在進度更新、執行結束及切換頁面後保持。達到容量上限時先移除最舊的已完成命令；單筆仍過長時依完整行裁剪較早內容，並在畫面、複製及匯出中顯示截斷提示。

重複出現的確認、就緒和連線狀態依接收順序保留，電壓變化及中斷／重新連線不會因去重而省略。PDO 重試保留兩次嘗試的狀態資訊，能力表顯示選定的一份結果；偵測依完整回覆中的狀態順序確定最終結果。

### 協定偵測

![協定偵測](../screenshots/zh-TW/light-detection.png)

[深色主題](../screenshots/zh-TW/dark-detection.png)

![協定偵測報告](../screenshots/zh-TW/light-protocol-report.png)

[深色主題](../screenshots/zh-TW/dark-protocol-report.png)

偵測結束後，點選偵測頁的 **匯出圖片報告**，可將本輪結果儲存為 16:9 PNG，選擇 1920×1080、2560×1440 或 3840×2160 及淺色／深色主題；首次主題跟隨目前介面，之後記住上次匯出選項，獨立於監控報告。報告包含儀表與偵測時間、完成狀態、全部協定結果、電壓檔位、PD 版本，以及本輪獨立讀取的完整 PDO 電壓／電流／功率參數，保留 SPR AVS 各分段。`*` 表示由最高電壓乘電流得到的參考功率，非實測或保證持續輸出；明確回傳的 PDP／功率直接顯示，`†` 標註 AVS 在最高電壓處的參考電流，缺失值顯示 `—`。部分完成、取消或逾時仍可匯出並明確標註，重設未確認時保留提示。開啟匯出視窗即固定本輪資料，後續偵測、讀取 PDO 或斷線不改變這份報告；儲存失敗不會以半成品覆寫既有檔案。

PD 不採用 `entry list`／`entry list+` 的狀態或附帶 PDO。其他協定掃描與補測結束後，獨立重設、進入 PD 並執行 `pd pdo`，依本次有效 PDO 判定支援情況；即使清單回報 PD 不支援，也會執行獨立檢查。取消後不會繼續讀取。

偵測進度與結束狀態顯示在標題旁；偵測前請先中斷下游負載，掃描及重設流程可查看偵測按鈕的提示。結果矩陣依 PD、標準協定和廠商協定分組，每項將協定名稱與狀態並列，直接顯示回傳的電壓檔位或範圍；PD 獨占一列顯示固定檔位與 PPS／AVS 範圍。單項 5 V 驗證只標記已驗證的 5 V，不推斷更高檔位；支援但未回傳電壓時顯示「未回傳電壓」。點擊卡片底部的「依據」展開本協定的結果來源、原因與原始回應；PD 只顯示獨立讀取的 PDO，不包含整輪掃描記錄。「用於觸發」與依據入口並列，僅填入表單。

`自動偵測` 先執行常規清單掃描，再逐項補測未取得明確結果的常規協定；`完整偵測` 不論 PDM 版本，一律先送出 `entry list+` 掃描 VOOC/SVOOC、MTK PE 等擴充協定，未收到結束標記時回退常規掃描後補測。明確不支援的項目不重試。舊版 PDM 未提供擴充結果時，相關項目標為「未檢查」。含回退與補測的時間預算分別約 4、7 分鐘，開啟與恢復串口另留少量時間。

結果區分「支援」「不支援」「未檢查」「未確認」，可展開原始回應與清單掃描／單項補測來源。PD 版本優先採用進入 PD 並獨立讀取有效 PDO 後取得的完整 `Get_Revision` 回應，同時顯示 PD 修訂號與規範版本；若標準回應不可用，則依序採用完整儀表掃描明確回報的 PD 3.0/3.1/3.2，以及 PDO 能證明的最低版本：PPS APDO 表示至少 PD 3.0，EPR PDO 表示至少 PD 3.1，SPR AVS PDO 表示至少 PD 3.2。只有一般固定 PDO 時無法推斷版本。儀表掃描版本與目前線纜模擬條件下獨立讀取的 PDO 分開顯示；版本查詢沿用目前的 PD 會話，不額外請求 5 V 檔位，也不改寫 PDM 的 `type / em / sink`。版本查詢失敗不會改變 PD 支援狀態、PDO 或整輪偵測結果。VOOC/SVOOC、MTK PE 1.0/2.0 分開顯示；MTK 空欄位保持為未確認，不依另一版本的結果推斷支援；不根據 PD/PPS 功率推斷 QC4/QC5 或品牌認證。新偵測清空上一輪結果與 PDO；取消或中斷保留本輪已收到的結果並標明未完成。

顯示版本時同時核對本項獨立讀取的結構化 PDO；較低或缺少的版本摘要不能覆蓋 SPR AVS 所證明的 PD 3.2 下限。若 `Get_Revision` 回傳較低版本，保留回應並明確提示版本依據衝突。

偵測會切換目前協定，但不會改寫已確認的 PDM 參數；QC/FCP/AFC/SFCP 補測包含 5 V 驗證，請先中斷下游負載。正常結束和取消後都立即嘗試重設並實測驗證 5 V，合計最多 15 秒。點擊支援且已有觸發實作之協定列中的 `用於觸發`，只會切換至 `觸發` 頁籤並填入表單，不會自動執行命令。讀取並選擇 PDO、檢查參數後再觸發。觸發回應被拒絕、為空或未確認不會顯示成功；進入協定的確認不能代替觸發確認，確認也不等於已實測達到目標電壓。

開啟 PDM 會依次套用點擊時選定的參數；重新開啟及 CDC 恢復時重播最近成功設定。頂部狀態區分目前選擇與裝置已確認套用的設定，並顯示可辨識的儀表韌體版本；PDM 版本另列於偵測診斷。套用失敗或自訂命令改變設定後，不把舊選擇當作已套用。

固定 PD PDO 的電壓由檔位編號決定，選取已知固定檔位後電壓唯讀，請求省略 `volt`。UFCS 能力保留原始 `NUM` 編號，點擊後填入 UFCS 請求。PPS／AVS 和未知編號保留手動輸入，不新增協定電壓、步進限制。

5 V 補測使用現有擷取連線的新鮮樣本：命令確認至少 500 ms 後，取連續五個樣本的中位數，容差為 200 mV 與目標電壓 3% 中的較大值，最多等待 12 秒並服從偵測總預算。過渡電壓會繼續等待新樣本；樣本不足或電壓不符時標示未確認，不顯示「已驗證 5 V」。取消期間維持忙碌，重設處理完成才解鎖。

進階 `pd data` 支援連續十六進位、帶 `0x` 的位元組及空白／逗號／冒號／短橫線分隔，非法字元不會被靜默丟棄。標準資料檢查 SOP、兩位元組標頭及物件長度，不含 CRC；未確認的擴充格式會提示並保留原始位元組。自訂命令執行後重新確認協定狀態。

## 檔案格式

### CSV

監控頁讀寫 CSV。表頭前包含點數、時長、取樣間隔和日期，之後可能有軟體、裝置及取樣規則來源。此單點範例啟用了溫度與標記：

```csv
SUM,1
TotalTime,="00:00:00.250"
SampTime(ms),250
DateTime,2026-10-17 12:00:00
Software,laPower 0.2.6
Device,WITRN K2 (0716:5060)
Points,mean

Time(D.hh:mm:ss.ms),Voltage(V),Current(A),Power(W),Temp(°C),D+(V),D-(V),CC1(V),CC2(V),RelativeTime(s),Timestamp(ms),RecordingSegment,SampleInterval(ms),Marker,
="00:00:00.250",5,0.5,2.5,25,0.6,0.1,1.6,0.3,0.25,1792209600250,1,250,Start,
```

- `包含溫度` 控制 `Temp(°C)`，`包含標記` 控制 `Marker`，`包含裝置資訊` 只控制 `Device` 來源行，不改變擷取和圖表資料。
- `="HH:MM:SS.mmm"` 使試算表以文字保留時間，超過一天會加天數。`RelativeTime(s)` 為精確相對秒，`Timestamp(ms)` 為絕對時間戳記。
- `RecordingSegment` 區分暫停前後的記錄段，`SampleInterval(ms)` 保存逐點間隔。可選的 `CurrentMagnitude(A)` 保留正反相抵前的電流幅值，維持容量重算一致。
- 數值保留匯出精度，缺失值留空；勾選溫度欄不代表有有效溫度。`Marker` 的標籤會在匯入時還原。
- 舊 CSV 缺少溫度、訊號線或新增尾欄仍可匯入，依表頭名稱辨識，不需手動補欄。來源缺失時保持未知，不使用目前儀表補填。

### PD 擷取

PD 使用 JSON，與監控 CSV 分開。現行格式標識為 `app: "laPower"`、`kind: "pd-capture"`、`version: 2`；version 1 舊擷取仍可匯入。匯入會驗證並取代目前 PD 擷取。只匯入 CSV 不會載入 PD JSON，聯合匯出的兩份檔案也需在各自工作區分別匯入。

## 常見問題

### 找不到裝置或連線失敗

使用儀表資料介面和支援資料傳輸的線材，重新整理後選擇儀表。關閉可能占用裝置的其他軟體，再重試或重新插拔。Linux 需設定 HID/Bulk 權限，見 [udev 規則](DEVELOPMENT.md#udev-規則必需)。支援型號見 [裝置清單](../../README.zh-TW.md#-支援的裝置)。

### 已連接但圖表沒有資料

連線只啟用即時預覽，請按 `開始記錄`。暫停後讀數仍可變化，但點數不增加，需按 `繼續記錄`。不相容或無效的儀表報告也可能沒有有效讀數。

### 溫度一直是 `--`

依 [溫度服務](#溫度服務) 選擇並連接來源。預設為外部 TCP，要使用儀表溫度需手動選擇儀表。曲線和 CSV 選項都不會啟用擷取。檢查伺服器、位址、連接埠與型號支援，部分韌體可能不提供有效溫度。

### PD 頁沒有新報文

檢查連線與跟隨模式，連動時需開始主監控記錄。重新插接被測連線才能產生新協商。獨立模式若暫停清單，需按 `繼續記錄` 才會顯示緩衝報文，也請檢查篩選條件。

### macOS 長時間記錄

記錄期間阻止自動睡眠，螢幕仍可熄滅；只連接或暫停不阻止睡眠。macOS 14+ 設定停用 WebView 背景節流；macOS 12–13 長時間記錄請保持視窗可見。合蓋或手動睡眠仍可能中斷 USB 擷取。

舊專案名為 WITRN-RS；laPower 使用獨立設定目錄，既有 CSV 與相容 PD 擷取可直接匯入。
