## 語言選擇

在「設定 → 外觀與語言 → 語言」可選擇跟隨系統、简体中文、繁體中文、English、日本語。切換立即生效並儲存偏好，保留連線、記錄、資料、圖表範圍、篩選和選中報文；重設設定回到自動模式。

Linux 按第一項非空的 LC_ALL → LC_MESSAGES → LANG 偵測；Windows／macOS 使用原生系統 locale。原生不可用時採用 WebView 首選語言，最終回退英文。Hans 優先選擇簡中、Hant 優先選擇繁中；否則 CN／SG 和無區域 zh 為簡中，TW／HK／MO 為繁中，ja 為日文，其餘含 C／POSIX 為英文。統一處理大小寫、下劃線、編碼與修飾後綴；手動選擇覆蓋自動偵測。

```bash
LANG=en_US.UTF-8 ./laPower.AppImage
LC_ALL=ja_JP.UTF-8 ./laPower.AppImage
env -u LC_ALL LC_MESSAGES=zh_TW.UTF-8 LANG=en_US.UTF-8 ./laPower.AppImage
```


## 介面總覽

視窗分三層：**標題列**（Tab + 裝置連線）、**工作區**（當前 Tab 的內容）、**狀態列**。

### 標題列

標題列同時承擔 Tab 條的職責，常顯監控、PD 分析和設定；連線 POWER-Z 後增加協定控制入口：

| Tab | 內容 |
| --- | --- |
| `監控` | 即時讀數、圖表、記錄與匯入匯出 |
| `PD 分析` | USB-PD 報文清單與逐欄位解碼 |
| `協定控制`（僅 POWER-Z） | PDM、PDO、協定偵測與電壓觸發 |
| `設定`（齒輪圖示） | 外觀與語言、圖表與記錄、快速鍵、復原與重設、關於 |

右側是**常駐的裝置連線區**：由左至右為裝置下拉框、重新整理按鈕、資訊圖示，以及隨狀態切換的 `連線` / `中斷連線` 按鈕。因為它在標題列上，所以在任何 Tab 都能連線或中斷連線裝置，不需要先切回監控頁。未連線時顯示 `連線`，已連線後同一顆按鈕變成 `中斷連線`。

裝置下拉框裡的名稱格式為：

```
WITRN K2                                    未能解析 USB 連接埠時
WITRN K2 (USB 4-4)                          解析出 USB 拓撲連接埠
WITRN K2 (USB 4-4) [介面 0 / Usage 0xFF00]   同一物理裝置有多個 HID 介面時
```

介面後綴只在同一物理裝置篩選後仍剩多個 HID 介面時才出現。未識別 PID 的維簡裝置顯示為 `未知 WITRN 裝置 (0716:XXXX)`。

### 裝置資訊

此按鈕只顯示資訊圖示，懸停提示 `裝置資訊`。未連線時也能使用，切換裝置或重新整理清單後同步更新。

標題列重新整理與連線按鈕之間的資訊圖示可開啟裝置詳情，顯示 `VID` / `PID` / `SN` 與裝置說明。優先顯示已連線裝置，否則顯示目前選取的裝置；未選取裝置時顯示空狀態，不中斷資料流。

> 維簡硬體的 USB 序列號是**生產批次日期**而不是單機編號，同批次的兩臺儀表會拿到相同的序列號。標題列裝置清單因此會帶上 USB 連接埠，以便區分插在不同口上的同型號儀表。

### 狀態列

底部狀態列常顯：`記錄:`（當前記錄狀態，**可點選**以開始或暫停記錄）、`時長:`（當前記錄累計時長）、`取樣:`（當前取樣率）、`點數:`（已擷取的資料點總數）、`剩餘:`（依記錄上限與取樣率估算的剩餘時間），以及右側的連線狀態指示（`已連線` / `未連線`）。未連線時點選 `記錄:` 不會開始記錄。

## 監控工作區

### 命令欄

| 控制項 | 說明 |
| --- | --- |
| `開始記錄` / `繼續記錄` / `暫停記錄` | 啟停記錄。按鈕文案隨狀態變化：無資料時為 `開始記錄`；已有資料（含匯入的資料）時為 `繼續記錄`，續接當前時間線且不清空已有資料；記錄中為 `暫停記錄` |
| `取樣率` | 下拉選擇，見下表 |
| `匯出 CSV │ ▾` | 主按鈕按已儲存選項選擇儲存位置；箭頭開啟 `包含溫度`、`包含裝置資訊`、`包含標記` 及 `同時匯出 CSV 和 PD 資料…` |
| `匯入 CSV` | 讀入此前匯出的 CSV，匯入後可從最後一個時間點繼續記錄 |
| `一鍵重設` | 暫停記錄後可用；清空圖表並重設統計與累計能量，跟隨模式下也清空 PD 報文 |
| `顯示` | 開啟通道顯示浮出面板 |
| `自動暫停 │ ▾` | 主按鈕啟用或停用自動暫停，啟用時反白；右側箭頭開啟設定浮出面板 |
| `溫度服務 │ ▾` | 主按鈕連線或中斷溫度來源，連線時反白；右側箭頭開啟設定，詳見 [外部溫度服務](DEVELOPMENT.md#外部溫度服務) |

命令欄保持單層，匯入和清空保留直接入口；小視窗可調整介面縮放。CSV 選項修改即儲存，面板保持開啟；預設不包含溫度、包含裝置資訊和打點，勾選但無資料時保留空列。

三個分割按鈕的主操作與箭頭獨立，開啟設定不會啟停功能。點擊面板外部可關閉；按 Escape 關閉後，焦點返回開啟面板的按鈕。

聯合匯出需要兩側都有資料，與目前連線無關。一次選擇位置產生 `名稱.csv` 與 `名稱.pd.json`，檢查兩個覆寫目標並分別回報結果。選擇位置後固定全部資料快照，不受選取範圍、篩選或後續追加、清空和編輯影響。PD 未跟隨記錄時提示時間範圍可能不同，不自動裁剪或對齊。

取樣率下拉的預設（括號內是實際的毫秒間隔，也是 CSV 裡 `SampTime(ms)` 的值）：

| 顯示 | 間隔 |
| --- | --- |
| `100 次/秒` | 10 ms |
| `10 次/秒` | 100 ms |
| `4 次/秒` | 250 ms（預設） |
| `2 次/秒` | 500 ms |
| `1 次/秒` | 1000 ms |
| `0.2 次/秒（5 秒 1 次）` | 5000 ms |
| `0.1 次/秒（10 秒 1 次）` | 10000 ms |

選中 POWER-Z KM003C / KM002C 時會額外顯示 `1000 次/秒`（1 ms）。該模式使用裝置的
AdcQueue，樣本帶 1 kHz 裝置時基；溫度由並行 ADC 快照補齊。認證或裝置韌體不支援高速隊列時，
應用會自動退回 `100 次/秒` 並提示原因。維簡 HID 裝置始終使用不小於 10 ms 的間隔。

後端 `set_sample_rate` 接受 1 – 60000 ms 的任意值，具體下限由裝置決定。匯入 CSV 使用檔案中的逐點間隔、摘要間隔或時間序列估算，不覆蓋持久化的取樣率設定；下拉框仍顯示下一次即時擷取的間隔。

儀表本身按固定節拍回報（維簡約每 10 ms 一幀）。取樣間隔更長時，電壓和 D+ / D− 取視窗內全部幀的平均值，時間戳記、CC1 / CC2 和溫度取最後一幀。啟用「記錄電流方向」時，電流取有符號均值（方向翻轉可相抵）；關閉時取逐幀電流幅值的均值。功率、累計能量和累計容量始終按逐幀幅值計算，避免正反向相抵後少計。比取樣間隔短的尖峰會被平均掉，需要看尖峰時請用 `100 次/秒`（POWER-Z 可用 `1000 次/秒`）。

取樣率同時決定**累計能量忽略多大的空檔**：相鄰兩點間隔超過 `max(2 秒, 8 × 取樣間隔)` 時那一段不計入積分（休眠、NTP 校時、漏採都屬於這一類）。所以在 `0.2 次/秒` / `0.1 次/秒` 這類慢檔下，空檔容忍會跟著放寬到 40 秒 / 80 秒，而不是把每一步都當成空洞。

### 打點標註

`打點 ▾` 位於圖表右上角，主體新增標記，箭頭開啟清單，可改名或刪除。

記錄充電測試這類長時間過程時，可以在關鍵時刻打點，例如手機電量到了 50%、拿起又放回、風扇開始轉。點擊 `打點` 或按 `M`，在彈出的輸入框裡寫標籤（預設是「標記 N」），按 Enter 確認。

- 在 `設定 → 圖表與記錄` 中開啟 `立即打點`，按鈕和快捷鍵會直接用「標記 N」新增標記，不彈出輸入框；之後可在標記清單中改名。此選項預設關閉，修改後自動儲存。
- 按下的那一刻就確定位置：記錄中標記落在之後到達的下一個點上，對話框開著時記錄照常進行；沒在記錄時落在最後一個點上。滑鼠停在主圖上時按 `M`，標記游標下最近的那個點，適合回看時補標。
- 主圖上每個標記是一條豎線，頂部顯示標籤，靠得很近的標籤最多錯開三行；時間線導航器上同步顯示細刻度。
- `打點` 右側的清單按鈕列出全部標記和時間：點擊標籤可以改名（留空即刪除），點 × 刪除。
- 標籤最長 40 個字元；逗號、分號、引號、換行會換成空格，開頭的 `=`、`+`、`-`、`@` 換成全形字元，避免被試算表當成公式。
- 標記屬於目前這份資料：`一鍵重設`、匯入另一份資料都會一併清掉；匯出 CSV 時寫進 `Marker` 列；記錄中打在新資料上的標記也會進入暫存復原檔案，補標在已寫入的舊點上的只在匯出的 CSV 裡。

### 讀數卡片

讀數欄隱藏捲軸且不預留空間；視窗較矮時，可在欄內用滾輪或觸控板上下捲動，查看全部讀數。

左欄可透過右側分欄條調整寬度（200–360 px，預設 250 px），拖動後儲存。窄視窗或矮視窗會將實際寬度收緊至 220 px 或 200 px。四張主卡（電壓 / 電流 / 功率 / 溫度）結構統一：

- 標題：通道色圓點 + 名稱；
- 下方圓角 **橫向電平條**只包住當前讀數：底色與填充為同一通道不同色度（底更淡、電平更飽和）；量程按工作階段觀察最大值自動取 1-2-5，填充從左向右；大字讀數居中並佔滿條的大部分，文字用常規文字色；
- 三列統計：`最小` / `平均` / `最大`（溫度卡為 `最低` / `平均` / `最高`）。

其餘卡片：

- **電流** —— 啟用「記錄電流方向」時數值前方顯示方向箭頭。
- **溫度** —— 卡片、顯示選項和匯出選項固定存在；未啟用、等待資料和連線中斷以文字與 `--` 表達。擷取、曲線顯示、CSV 溫度列獨立控制。斷線保留來源、偏好和歷史資料，不自動重連或換源，缺失區間留空。清空、匯入不改變連線偏好；匯入溫度不觸發連線，重啟後需手動連線。`儀表` 來源隨儀表斷線結束，`外部` TCP 獨立。
- **累計能量 (Wh)** 與 **累計容量 (mAh)** —— 由軟體對取樣點積分得出，不是儀表內部的累加器。以兩行顯示累計值。`一鍵重設` 會歸零，匯入檔案則依匯入資料重新計算；暫停後繼續記錄時累計值保留，且暫停期間的時長不計入積分。間隔超過 `max(2 秒, 8 × 取樣間隔)` 的空檔同樣不計入（見上文取樣率一節）。
- **訊號線** —— D+ / D- / CC1 / CC2 四路電壓，每格名稱 + 數值，下方一條水平迷你條。顯示保留兩位小數，實際解析度取決於裝置；WITRN CC1 / CC2 為 0.1 V。

圖表無資料時，圖表區域疊一層空狀態：「連線裝置後點選開始記錄」。開始記錄並寫入第一個點後消失。

### `顯示` 浮出面板

- 四條主曲線 `電壓` / `電流` / `功率` / `溫度` 各有一個顯隱勾選框和一個**填充不透明度**輸入（0 = 關閉填充，1–100 = 開啟填充，預設 15）。
- `D+ / D-` —— 在圖表中疊加兩條訊號線曲線，共用電壓座標軸。預設關閉。
- `CC1 / CC2` —— 同上，共用電壓座標軸。預設關閉。
- `僅統計選取範圍` —— 勾選後，讀數卡上的最小 / 最大 / 平均以及累計能量、容量都只統計時間線導航器當前選中的範圍。預設關閉。非有限的樣本值（匯入的 CSV 裡空著或寫成 `NaN` / `Inf` 的那些）不參與最小 / 最大 / 平均，均值旁會以 tooltip 說明被排除的點數；`統計範圍` 標籤裡的「(N點)」仍是選中區間的原始行數，不是參與計算的點數。

### `自動暫停` 浮出面板

用於無人值守測試：當被測量持續低於閾值一段時間後自動暫停記錄。

先用右側箭頭設定條件、閾值與持續時間，再點擊 `自動暫停` 主按鈕啟用。預設停用；條件為 `無` 時，即使主按鈕反白也不會觸發。修改設定不會自動啟用。

| 欄位 | 取值 |
| --- | --- |
| `條件` | `無`（預設，即關閉） / `電壓 <` / `電流 <` / `功率 <` |
| `閾值` | 數值，單位隨所選條件自動切換 |
| `持續時間` | 秒。必須連續滿足條件這麼久才觸發 |

### 圖表與時間線

主圖最多同時繪製 8 條曲線，共用 4 條 Y 軸：**電流 (A)**、**電壓 (V)**、**功率 (W)**、**溫度 (°C)**，四軸刻度嚴格共線。D+ / D− / CC1 / CC2 共用電壓軸。

- **tooltip** —— 懸停顯示該時刻可見且有有效數值的通道及相對時間（`HH:MM:SS.d`）。
- **圖例** —— 顯示目前可見曲線的名稱與顏色；透過 `顯示` 浮出面板切換曲線顯隱。
- **時間線導航器** —— 底部縮略圖，拖動兩端手柄選取範圍，拖動中間高亮選區可平移視窗（跨度不變）；中間顯示 `時長:` 與該範圍的點數。
- **滾輪橫向縮放** —— 在主圖上捲動，以光標所在時刻為錨縮放時間窗。向上/向前拉近，向下/向後拉遠。錄製中同樣可用：視窗右沿貼著最新點時跟最新走（時長不變），看歷史時則定住該片段。滑塊會跟著動；暫停後再繼續記錄不會丟掉當前視窗。
- 密集資料自動切換為增量 min/max 像素桶渲染，完整資料仍保留在列式存儲裡；懸停時二分回查原始取樣點，讀到的是真實值而非降取樣值。回看按畫布的實際像素解析度保留曲線細節，高 DPI 下也不會用寬桶替代精細曲線；拖動中和鬆手後採用相同投影，放大到每個畫布像素不超過一個取樣點時恢復原始點及視窗兩側鄰點。

1000 次/秒取樣時，曲線自動更新預設約 20 影格/秒，繪製壓力較高時可降至約 10 影格/秒；拖動手柄、平移選區、滾輪縮放和鍵盤調整會獨立更新，鬆手後提交最終視窗。100 次/秒的健康繪圖不會因歷史變長固定降更新率。更新頻率只影響曲線顯示，全部取樣點、CSV、統計和能量積分仍完整保留。錄製預算與回看預算獨立；回看慢影格可暫時關閉面積填充並採用像素列繪製，曲線精細度保持不變。

## PD 分析工作區

### 命令欄

| 控制項 | 說明 |
| --- | --- |
| `開始記錄` / `繼續記錄` / `暫停記錄` | 跟隨模式下啟停記錄；獨立模式下繼續或暫停清單更新，背景繼續緩衝報文 |
| `清空` | 清空報文清單 |
| `匯出` / `匯入` | PD 擷取的 JSON 存取 |
| `依報文類型篩選…` | 文字輸入，按訊息類型名篩選清單 |
| `隱藏 GoodCRC` | GoodCRC 是鏈路層確認訊框，數量通常佔一半以上，隱藏後清單可讀性大幅提升 |
| `自動捲動` | 出現新報文時自動捲動到底部 |
| `跟隨記錄` | 與主監控聯動，見下 |
| 分欄方向 | 寬屏（視窗寬度 ≥ 1400px）時可改為左右分欄（清單約 55% / 詳情約 45%）；偏好會儲存，窄視窗仍回到上下佈局 |

命令欄右側顯示當前報文條數與狀態，例如 `356 條報文 / 等待記錄`。

#### `跟隨記錄`（預設開啟）

開啟後 PD 分析與主監控**完全聯動**：

- 僅在主監控記錄時擷取 PD 報文，未記錄時報文直接丟棄、不進緩衝；
- 左側的開始 / 暫停按鈕同時控制主監控的記錄；
- 兩側的清空互相聯動，清空任意一側都會同時清空圖表與報文。

關閉後三者互不影響：PD 獨立擷取、獨立暫停、獨立清空。

### 報文清單

| 列 | 含義 |
| --- | --- |
| `#` | 序號 |
| `經過時間` | 相對首訊框的時間，精度到毫秒 |
| `SOP` | `SOP`（端到端）/ `SOP'`（到線材晶片）等起始序列類型 |
| `Msg` | 訊息類型徽章，按類別著色 |
| `ID` | Message ID（0–7 循環） |
| `方向` | 角色方向徽章，如 `SRC → SNK`、`SRC ← SNK`、`SRC\|SNK → Plug` |
| `Obj` | 攜帶的 Data Object 個數 |
| `Rev` | USB-PD 規範版本 |
| `V/I` | 最近一次儀表取樣的電壓 / 電流，不保證與報文同時 |
| `摘要` | 速覽摘要 |

`摘要` 列是快速定位協商過程的關鍵，幾種典型內容：

```
Fixed: 5.0V 9.0V 12.0V 15.0V 20.0V SPR AVS: 9-15V@3.0A 15-20V@5.0A PPS: 5.0-21.0V
Position:1 Fixed:5.0V,3.0A
Position:7 PPS:8.0V,3.45A
0xFF00 Discover Identity REQ
```

即：Source_Capabilities 直接列出充電器廣播的全部檔位，Request 直接給出裝置選了第幾檔、要求多少電壓電流。

### 詳情面板

點選任意報文行，詳情面板把該訊框拆成三層：

1. **原始資料** —— `SOP*`、`Msg Header` 與 `Data Object 0..N` 的十六進位值。
2. **報文頭欄位表** —— `Extended` / `Objects` / `Msg ID` / `Power Role` / `Spec Rev` / `Data Role` / `Msg Type`。
3. **每個 PDO / RDO 的位域表** —— 例如 `PDO 1 5.0V,3.0A FPDO 0x0A81912C` 展開為 `Supply Type`、`Dual-Role Power`、`USB Suspend Supported`、`Unconstrained Power`、`USB Communications Capable`、`Dual-Role Data`、`Unchunked Extended Messages Supported`、`EPR Capable`、`Peak Current`、`Voltage`、`Maximum Current` 等逐欄位取值。

> **抓包建議：** 資訊量最大的時刻是**插拔充電器的瞬間** —— 完整的 Discover Identity → Source_Capabilities → Request → Accept → PS_RDY 握手都在最初幾十毫秒內完成。裝置已經協商好之後再開始記錄，只能看到週期性的 PPS 微調。

## POWER-Z 協定控制

連線 POWER-Z KM003C / KM002C 後，標題列會顯示 `協定控制` Tab。該頁通過裝置的虛擬序列埠執行
PDM、PDO 讀取、PD/PPS/AVS 請求、QC/FCP/SCP/UFCS 偵測與取消；即時電壓、電流、功率讀數仍來自
同一裝置的 Bulk 擷取流。命令執行期間可以點 `取消`，中斷連線或 Bulk 重連會自動結束當前 PDM 工作階段。

維簡裝置不會顯示這個 Tab，也不會發送任何控制命令。

## 設定頁

點擊標題列右側的齒輪按鈕進入；macOS 上也可以按 ⌘, 或從應用程式選單選擇「Settings…」。設定保留單頁捲動，依外觀與語言、圖表與記錄、快速鍵、復原與重設、關於排列。寬螢幕目錄固定在左側，小於 980px 時改為頂部橫向目錄；點擊平滑定位，手動捲動同步反白，返回設定時保留本次工作階段的位置。捲軸維持固定寬度，避免懸停時擠動內容。

目錄可用 Tab 聚焦、Enter 跳轉。系統開啟「減少動態效果」時即時定位；返回設定頁也即時復原位置，不播放捲動動畫。

## 檔案格式

### CSV

匯出檔案為中繼資料行 + 1 個空行 + 表頭 + 資料行。前 4 行中繼資料固定，之後是來源行：

```csv
SUM,1
TotalTime,="00:00:00.000"
SampTime(ms),250
DateTime,2026-08-23 00:15:42
Software,laPower 0.2.5
Device,WITRN K2 (0716:5060)
Points,mean

Time(D.hh:mm:ss.ms),Voltage(V),Current(A),Power(W),Temp(°C),D+(V),D-(V),CC1(V),CC2(V),RelativeTime(s),Timestamp(ms),RecordingSegment,SampleInterval(ms),
="00:00:00.000",9.0991,0.0646,0.58820186,31.5,0.61,0.02,0.5,1.6,0,1787415342000,1,250,
```

- `包含溫度` 控制 `Temp(°C)` 列，勾選但無資料時保留空列。
- 時間列寫成 `="HH:MM:SS.mmm"` 的形式是為了讓 Excel 按文字而不是日期解析。超過一天時前綴天數，形如 `="1.02:03:04.500"`。
- 數值列使用可往返的十進位文字，保留原始精度與電流符號，不按介面顯示的小數位數截斷。缺失值留空；裝置的實際解析度因通道和型號而異。
- `RelativeTime(s)` 儲存精確相對秒，`Timestamp(ms)` 儲存絕對時間戳記；`RecordingSegment` 為可選列，用來區分記錄段，暫停期間不積分。`SampleInterval(ms)` 儲存逐點取樣間隔，支援混合取樣率。舊檔案缺少這些尾列時仍可匯入。
- `Marker` 為可選列，保存打點標籤：標籤寫在它所在的那一行，其餘行留空；取消 `包含標記` 時省略此列，勾選但無標記時保留空列。暫存復原格式不變，始終帶此列。
- `Software` / `Device` / `Points` 是來源行：寫檔案的軟體與版本；擷取這份資料的儀表（型號與 USB VID:PID，匯入後繼續用另一台儀表記錄時追加，用 ` / ` 分隔）；每個點怎麼從儀表幀得到（`mean` 表示取樣間隔內全部儀表幀的平均值，間隔等於儀表節拍時就是那一幀）。來源混合或未知（例如接著舊檔案記錄）時不寫 `Points`。匯入時讀取並在再次匯出時保留；沒有這幾行的舊檔案照常匯入。
- `CurrentMagnitude(A)` 是可選欄，用來保留同一視窗內正反向相抵時的電流幅值，確保再次匯入後容量與錄製時一致；缺省或空儲存格回退至 `abs(Current(A))`。一般匯出僅在需要時帶此欄，暫存恢復檔固定帶此欄。舊檔仍可匯入，但先前已相抵且未儲存的幅值無法恢復。
- 訊號線列在資料缺失時留空，因此**不含這四列的舊檔案仍可匯入** —— 匯入邏輯按表頭名匹配列，不依賴列序。

`包含裝置資訊` 只控制 `Device` 來源行，不影響軟體版本或取樣規則。來源取自記錄，匯入檔案缺失來源時不使用目前裝置補填。匯出選項不改變擷取、顯示、記憶體資料或暫存復原檔案。

### PD 擷取

匯出為 JSON 信封：

```json
{
  "app": "laPower",
  "kind": "pd-capture",
  "version": 2,
  "exportedAt": "2026-08-23T00:15:42.000Z",
  "entries": []
}
```

`version: 2` 是當前的緊湊格式；`version: 1` 的舊樹形格式仍可匯入。匯入時會校驗 `kind` 與 `version`，不匹配會給出明確報錯而不是靜默失敗。

匯入的報文與即時擷取的報文使用不同的記錄代號（generation），因此匯入一份歷史擷取不會和當前即時流互相串號。

## 常見問題

### 裝置未被識別

- 確認裝置已在下拉框中出現 —— 點選重新整理按鈕重新掃描。
- WITRN 按 VID `0x0716` 列舉，POWER-Z KM003C/KM002C 按 VID `0x5FC9` 的 Vendor Bulk 介面列舉。沒有出現時，檢查資料線與 USB 連接埠是否支援資料傳輸。
- 嘗試重新插拔。

### 連線失敗

- 檢查裝置是否被其他上位機程式佔用（同一 HID 介面不能被兩個程式同時獨佔開啟）。
- 關閉其他 WITRN 上位機後重試，或重啟本應用。

### Linux 下掃不到任何裝置

這幾乎總是**權限問題**而不是識別問題：`hidapi` 需要開啟 `/dev/hidrawN`，預設只有 root 有權限，普通使用者運行時會「啟動正常但裝置清單為空」且沒有任何報錯。

解決方法見 [開發與建置 · udev 規則](DEVELOPMENT.md#udev-規則必需)。

### macOS 上長時間無人值守記錄

- 記錄期間，本應用程式會阻止系統閒置睡眠；螢幕照常熄滅，暫停或停止記錄後恢復。只擷取而不記錄時，仍遵循系統睡眠設定。
- 闔上螢幕或手動選擇睡眠仍會讓 Mac 睡眠；記錄期間請避免這兩項操作。
- macOS 14+ 上，最小化、隱藏或遮擋視窗不會暫停擷取；macOS 12–13 無法關閉 WKWebView 的背景節流，長時間記錄時請保持視窗可見。

### 資料顯示異常

- 確認裝置型號在[支援清單](../../README.zh-TW.md#-支援的裝置)中。顯示為「未知 WITRN 裝置」的型號能否正常讀數取決於其韌體是否使用相同的報告結構。
- 解析器會拒絕訊框頭錯誤或電壓 / 電流明顯超出物理範圍的報告，所以異常韌體通常表現為「連上了但沒有資料」而不是顯示錯誤數值。

### 溫度一直是 `--`

- 溫度源預設是 `外部`（TCP）。如果你要用儀表自帶的溫度，需要在 `溫度服務` 浮出面板把 `來源` 切到 `儀表`。
- 用外部 TCP 源時，檢查 IP 與連接埠、以及伺服器發送的是否為純數字加換行。詳見 [外部溫度服務](DEVELOPMENT.md#外部溫度服務)。
- 溫度位元組偏移只在部分型號上驗證過。溫度越界時解析器按「無溫度」處理，不會因此丟棄整訊框資料 —— 所以電壓電流正常而溫度恆為 `--` 是可能的。
