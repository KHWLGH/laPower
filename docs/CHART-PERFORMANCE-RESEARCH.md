## 实现与数据边界

主图每桶、每通道保留首点、末点、最小值点、最大值点的源下标，按采样顺序排序并去重。极值相等时保留最早下标，保持正负零；候选点读取原始列的真实时间，重复时间不增加偏移。每通道使用独立、有界、可复用的候选缓冲，不将八通道候选点合并成巨大共享序列。uPlot 的共享数组仅承载坐标和光标，光标及提示仍二分查询原始样本。

样本数分桶、二倍合并和尾桶增量追加继续保留。合并、重新扫描、热索引和部分索引查询产生相同候选点。只有两候选点之间的全部原始样本都为有限值时才连接，因此桶内被省略的 NaN 也会打断描边和填充。分页节点只存八通道的最小下标、最大下标、有限值数量，值从原始列读取；每页 256 节点、24 KiB，叶块 32 点。360 万点缓冲从 29,097,984 B 降为 21,823,488 B（减少 25%），追加不复制已有页。

密集位图直接使用有序几何，跳过会被丢弃的标准路径。每条线段按设备像素列求覆盖区间，再合并同列重叠区间，避免陡坡沿纵向逐像素反复描画。缺测两侧不创建连接。无 OffscreenCanvas 或颜色／透明度不适用时，使用相同几何生成 Canvas 路径。填充沿相同线段形成独立区域，保留基线、通道顺序和现有填充保护。功率导航图使用相同的有序几何，预算仍是每两个 CSS 像素一桶。原始点窗口和往返复杂度保护保留，完全放大统一采用线性连接。

冷暂停先复用同数据源、同范围的完整录制投影，同步只补齐至多 4096 点尾部，不为首图扫描全部历史。后台以 1 ms 协作预算、每步至多 1024 点追赶索引，私下完成精细桶后一次原子替换。新窗口、恢复录制、隐藏或换源取消过期任务；已完成索引前缀保留。填充保护可能重绘相同精细几何，验收统计几何从粗到细的转换次数，同时保留每个实际 draw，避免将保护重绘误报成第二次升级。

原始记录、统计、积分、CSV、恢复文件、公开配置与记录容量换算没有修改。

## 热查询与追加

Node 配对查询每种点数预热 5 次、测量 20 次，交替查询顺序。100 万点热查询中位：快照 3.81 ms，当前 2.67 ms；360 万点：4.51 ms 与 3.28 ms，分别为快照的 70%／73%，满足中位耗时回退不超过 15% 的目标。查询与几何物化分开记录，缺测检查在物化几何时读取有限计数，不反复付给每个热查询。输入、窗口相位和快照固定。冷建索引中位约 30.7／118.0 ms，另列而不计入热查询。

100 万／360 万点追加 128 点的索引中位约 0.0048／0.0038 ms，已有页复制均为 0 B。下降斜坡候选点中虚构上升段为 0，重复时间没有人为偏移。Node 数据用于算法比较，不代表浏览器 FPS。

## WebView2 合成验证

使用重新编译的原生 debug 应用和 WebView2 155.0.4283.45，通过本地 CDP 驱动。DPI 1／1.25／1.5／2 均在子进程启动时强制设置并核对 `devicePixelRatio`；100 万／360 万点、普通／强交变、八通道带填充各三轮。检查冷首图、一次细节升级、连续缩放平移、松手稳定、隐藏恢复及换源。验收脚本核对正在运行的索引容量，防止意外使用旧前端或混合模块。

快照与当前分别内嵌到独立二进制，核对 360 万点的索引分别为 29.10／21.82 MB；两版各 48 次场景运行，无页面异常。结果如下，所有数值为 p95：

| 指标 | 本轮快照 | 当前 |
| --- | ---: | ---: |
| 100 万点冷首张完整图 | 118.7 ms | 25.0 ms |
| 360 万点冷首张完整图 | 162.6 ms | 24.4 ms |
| 100 万点首次精细图 | 118.7 ms | 106.8 ms |
| 360 万点首次精细图 | 162.6 ms | 180.3 ms |
| 强交变连续手势帧间隔 | 90.9 ms | 45.1 ms |

原生强交变手势最大帧间隔从 110.1 ms 降至 52.4 ms，仍存在超过 33 ms 的帧，不能宣称原生八通道带填充始终达到 60 FPS。冷首图达到目标，首次精细图仍有后台等待。浏览器矩阵与 WebView2 单独报告。未完成真实 KM003C 的 HID、原生暂停尾点栅栏、恢复文件写入和硬件长记录验收；不以浏览器或合成 WebView2 结果替代。

## 杂点与正确性检查

上一轮定位的屏幕分立短条来自旧位图只按横向距离判断连接，陡坡纵向范围不相交时未补线。本轮快照已修复该问题，因此本轮不重复用最初版本的巨大分量差异宣称提速。48 个正弦截图场景再次覆盖四档 DPI 和 12000／8000／4000／2000／1200／1000 点窗口；DPI 2 的前三个窗口中，快照和当前都为 4 个颜色连通分量，主曲线连续，少量边缘抗锯齿小分量仍保留。连通分量是像素诊断，不是原始采样点。

现有核心测试扩展了下降斜坡、尖峰、阶跃、重复时间、负值、正负零、桶内缺测、跨页查询、部分索引、尾桶追加及合并／重建等价。暂停测试让后台任务停住，确认首图没有同步扫描历史；在此期间补尾点并取消窗口／恢复录制／隐藏／换源，确认只发布完整匹配结果。描边、填充和无位图回退使用相同候选几何。
