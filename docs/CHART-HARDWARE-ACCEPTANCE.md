# KM003C 图表真机验收补充

后续实现与新基线配对验收见 [图表暂停与交互性能修复](CHART-PAUSE-PERFORMANCE.md)。本页保留原始长记录结果。后续复查发现本页手动驱动把目标 12% 填充传成了 0.12%；下文时间是该实际参数的测量，不能作为 12% 填充结论。

2026-10-16，续验 [有序降采样实施与合成基准](CHART-PERFORMANCE-RESEARCH.md)。应用已接收样本、CSV 与恢复导入的一致性，以及过渡正确性通过；**真机暂停延迟超过 33 ms，仪表队列还报告了序号空洞，因此本轮不能判定性能与硬件验收全部通过**。本次未修改生产源码。

## 环境与记录规模

- 同一台 Windows / Core Ultra 9 285H，当前 debug 原生程序，WebView2 155.0.4283.45，DPI 1.5。
- 实际连接 POWER-Z KM003C，USB VID:PID `5FC9:0063`，以仪表 AdcQueue / USB bulk 路径采集 1KSPS；没有用浏览器夹具替代原生采集，也没有执行电压或协议诱骗控制。
- 香港时间 19:41:24 至 20:06:06，约 24 分 42 秒，期间反复暂停、恢复和缩放；最终保留 **1,434,583 点、31 个记录段**，相对记录时间约 1434.55 秒。
- 会话截至断开前处理序号 1,483,495。该数包含暂停期间的预览点，不能与保留记录点数混为丢点统计。逐段核对原生批次中的选中样本数与保留列段号直方图，31 段全部一致，段内序号空洞为 0；流错误、容量错误、页面异常均为 0。
- 显示八个通道，七个测量通道有有限值；本次仪表未提供有效温度，温度列为缺测。电压最高约 8.9 mV、电流最高约 2.0 mA，属于当前接线下的低电平实测信号，不能替代带载、强交变或八路均有效的硬件验收。

启动时保存源码与 SHA-256；退出前从 WebView2 实际加载的三个图表模块回读并计算指纹，与工作区逐一一致。测试后生产源码指纹未变。原生二进制 SHA-256 为 `ec1f7658334268a526ff5156d8ec72d2d1ca726a9fbd32d67efc01c5788a54b2`。

**硬件采集端另有未通过项。** `native-stderr.log` 第 8 行报告 `KM003C AdcQueue 检测到 10 个序号空洞`，第 177 行报告 `已核实并跳过 44 个重放样本`。这是仪表队列的协议序号，和前端 IPC 中连续的选中样本序号不是同一个计数。当前代码对这两类情况仅做首次日志报告，不能把上述数值当作整个会话累计总数，也不能用应用流错误为 0 宣称仪表端零丢点。重放按完整样本内容验证后去重，未作为重复记录保存；空洞来源尚未定位，需继续排查仪表队列、USB 读取与主机负载，不能归因于图表降采样。

## 性能结果与未达标项

以下是约 **131 万点**、DPI 1.5、八通道显示并请求 12% 填充的受控复测。每种暂停三轮；冷场景先建立完整录制投影，再清空索引，保证测试真正经过粗图与后台精细化。按 nearest-rank 计算；只有三次时 p95 就是最大值，不能视为充分的尾延迟估计。

| 指标 | 三轮值（ms） | p95（ms） | 判断 |
| --- | --- | ---: | --- |
| 热暂停首张完整图 | 50.3 / 46.0 / 45.3 | **50.3** | 超过 33 ms |
| 冷暂停首张完整图 | 9.8 / 63.6 / 13.6 | **63.6** | 超过 33 ms |
| 冷暂停首次精细图 | 153.6 / 205.2 / 180.9 | 205.2 | 单列后台完成时间，没有冒充首图 |

六次暂停的原生尾点栅栏耗时为 53.5–118.5 ms，另行记录，不把它与 JS 绘图回调或物理显示呈现混为同一个指标。此前自然热状态下的约 111 万点三轮热暂停首张完整图为 51.5 / 39.6 / 31.9 ms，也没有稳定达到 33 ms。

暂停后的 rAF 间隔 p95 为 33.4 ms、最大 50.1 ms。受控连续缩放循环的动作间隔 p95 为 66.3 ms、最大 87.4 ms；该值含主机调度和图表刷新，不能称为 GPU 帧耗时。未对当前实测信号重跑实施前原生版本，故本次不给出真机手势提速比，也不把它与此前强交变合成结果混算。索引缓冲在约 131 万点时为 8,208,384 B；360 万点 21.82 MB 的结论仍来自此前完整基准，不是本次硬件录制规模。

因此后续仍应优化原生带填充连续交互和暂停请求至完整 draw 的尾延迟，并为仪表队列空洞、重放增加可累计的诊断后复测。此前浏览器和合成 WebView2 达标不能覆盖本次真机超时及队列空洞结果。
